# Paleta padrão: escura

Tema escuro: fundo verde quase preto, texto creme e verde sálvia como destaque.
Texto sobre o verde usa `on-primary`, nunca creme.

Para outra paleta neste vídeo, troque os valores acima. Apague este arquivo só se o vídeo tiver look próprio no `SPEC.md`.
