# Paleta padrão: escura

Tema escuro do HyperCut: fundo verde quase preto (`#14170f`), cartões `#1b1f15`, texto creme `#edeee3` e verde sálvia `#7bb289` como destaque.
Texto sobre fundo verde claro usa `#14170f` (`on-primary`); onde o texto for branco ou creme fixo, o fundo de destaque usa `#3f7a53` (`primary-deep`).

Para outra paleta neste post, troque os valores acima e as variáveis em `slides/base.css` (ou use as classes `.tema-claro` ou `.tema-editorial` no `<body>`).
