# Código de conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).
Ele vale para issues, pull requests e qualquer outro espaço do projeto.

Em resumo: trate as pessoas com respeito, critique ideias e não quem as propôs, e não tolere assédio.

Para relatar um problema, use a opção "Report content" do GitHub no comentário ou "Report abuse" no perfil.
Quem mantém o projeto pode editar ou remover conteúdo e bloquear contas que descumprirem este código.
