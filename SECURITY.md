# Política de segurança

## Versões cobertas

Só a `main` recebe correções.

## Como relatar

Não abra issue pública. Use o [relato privado de vulnerabilidade](https://github.com/WesleyDev184/HyperCut/security/advisories/new) do GitHub e informe:

- o que acontece e qual o impacto;
- os passos para reproduzir;
- a versão ou o commit afetado.

O projeto é mantido de forma voluntária, sem prazo garantido de resposta. Os relatos são lidos e tratados com prioridade.

## Escopo

Entram scripts, skills e configuração deste repositório. Falha no HyperFrames, no FFmpeg ou em outra dependência
deve ir para o projeto original, listado no [TERCEIROS.md](TERCEIROS.md).
